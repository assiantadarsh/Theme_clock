# 🕒 Theme Clock

A modern and responsive **Theme Clock** built using **HTML, CSS, and JavaScript** with a beautiful UI and smooth **Dark Mode / Light Mode** feature.

🔗 **Live Demo:**  https://assiantadarsh.github.io/Theme_clock/

## ✨ Features

✔ Real-time clock  
✔ Dark Mode / Light Mode toggle  
✔ Clean and modern UI  
✔ Fully responsive design  
✔ Smooth user experience  
✔ Built using pure HTML, CSS & JavaScript
